# Campus Assistant — AI Assistant for Moodle

Self-hosted AI assistant for Moodle. 48 functions for students, teachers, and administrators. Runs on your server — no data leaves your institution.

## Features

- **48 multi-role functions** — 20 for students, 12 for teachers, 16 for administrators
- **Multi-provider** — OpenAI, DeepSeek, Google Gemini, Anthropic Claude
- **Self-hosted** — all data stays on your server. Only LLM API calls go out.
- **Fixed pricing** — €499/year, unlimited users. No per-seat fees.
- **Security** — prompt injection detection, output sanitisation, rate limiting, audit logging, GDPR-compliant privacy API
- **Brandable** — custom logo, colours, assistant name, position
- **6 languages** — Spanish, English, French, German, Italian, Portuguese

## Requirements

- Moodle 4.1+
- PHP 8.0+
- API key for one of: OpenAI, DeepSeek, Google Gemini, or Anthropic Claude

## Installation

1. Download the plugin ZIP
2. Moodle Admin → Site Administration → Plugins → Install Plugins
3. Upload ZIP → follow installation wizard
4. Configure provider + API key in plugin settings
5. The assistant appears on every page
